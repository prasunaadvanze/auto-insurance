# PWA Setup Guide

Your Next.js app is now configured for PWA (Progressive Web App). Users can install it as a desktop app!

## ✅ Completed Setup

1. **next-pwa package** - Added to dependencies
2. **Manifest file** - Created at `/public/manifest.json`
3. **Next.js config** - Updated with PWA settings
4. **Meta tags** - Added to layout for iOS and Android support
5. **Icon template** - Created at `/public/icon.svg`

## 📋 Next Steps: Generate App Icons

You need to create PNG icons from the provided SVG. Here are your options:

### Option 1: Using Online Tools (Easiest)
1. Go to [icoconvert.com](https://icoconvert.com) or [CloudConvert](https://cloudconvert.com)
2. Upload `/public/icon.svg`
3. Convert to PNG and download these sizes:
   - `icon-192x192.png` - For main app icon
   - `icon-512x512.png` - For splash screen
   - `screenshot-540x720.png` - For mobile screenshots (optional)
   - `screenshot-1280x720.png` - For desktop screenshots (optional)
4. Save them to `/public/`

### Option 2: Using ImageMagick (Windows)
```powershell
# Install ImageMagick if needed: choco install imagemagick

convert public/icon.svg -resize 192x192 public/icon-192x192.png
convert public/icon.svg -resize 512x512 public/icon-512x512.png
```

### Option 3: Using GIMP
1. Open `/public/icon.svg` in GIMP
2. Export as PNG for each size needed
3. Save to `/public/`

## 🚀 Testing the PWA

### Install Dependencies
```bash
npm install
```

### Build for Production (Required for PWA to work)
```bash
npm run build
npm start
```

### Install on Different Platforms

**Windows/Mac:**
1. Open the app in Chrome or Edge
2. Click the **Install** button in the address bar
3. App will be installed to your desktop/applications menu

**iOS:**
1. Open Safari
2. Tap **Share** → **Add to Home Screen**
3. App appears on home screen

**Android:**
1. Open Chrome
2. Tap menu (three dots) → **Install app** or **Add to Home Screen**
3. App appears on home screen

## 🔧 Customization

Edit `/public/manifest.json` to:
- Change `theme_color` for app bar color
- Update `background_color` for splash screen
- Add more app `shortcuts`
- Customize `categories` and `screenshots`

## ⚡ Notes

- PWA is disabled in development mode (`npm run dev`) to avoid caching issues
- Service worker automatically generated by next-pwa
- Manifest auto-linked in HTML head
- Works best on HTTPS (localhost works for testing)
